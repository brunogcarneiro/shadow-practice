# Security Policy

## Reporting

Do not open a public issue for a vulnerability or exposed credential. Use GitHub's
private vulnerability reporting for this repository. Include impact, reproduction,
and a suggested mitigation when possible. You should receive an acknowledgment within
seven days.

Only the latest release is supported. Never attach real recordings or transcripts to
a report; provide a synthetic reproduction. Tokens previously used with a development
checkout must be revoked and replaced before publishing or distributing that checkout.
